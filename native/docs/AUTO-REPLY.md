# 自动应答：配置和使用

这是普通项目和原生Session的专项视图。没有新的Agent后台、检索引擎或任务平台。原上下文中心、CRM和原网关回调继续运行。

## 配置一次

1. 左侧「自动化应答」→「创建自动化应答项目」。
2. 部署环境安装一个标准消息连接器，并将对应Transport允许给该项目。私有凭证留环境变量，浏览器与模型不读取。
3. 在「接入设置」选择渠道账号、默认专家Skill、公共资料板块。默认方法为customer-reply；新专家只换方法包，不改宿主。
4. 如需个人资料，选择该资料板块及可信身份字段。留空按记录ID匹配；默认优先使用网关确认的externalUserId，缺失才用账号内contactId。只精确匹配一条；无匹配不猜，多条匹配暂停并转人工。
5. 选择是否提醒今日及本人，通知目标沿用今日已有配置；最后启用。未完成真实账号验收时保持停用。

资源先在通用资源库注册并发布，且对该项目开放。公共资料勾选即允许该账号下客户查询该板块，请把客户私有信息放个人资料绑定板块。变更资料/专家/启停将递增配置版本，旧草稿不能在恢复后补发。

## 一条消息怎么处理

可信私聊新消息→MySQL持久去重→固定客户Session与资料版本→Temporal交给原生Harness→加载所选Skill→读取本客户资料、检索选定公共资料→回复/忽略/转人工→保存发送结果与回执。

同一客户按入站顺序处理，前条请求返回受理/失败/未知后才放行后条。每条原消息、原任务和原外发编号保持不变。Host繁忙/重启由Temporal退避恢复，不重新编号；模型轮结束未提交处理结果或超过5分钟则转人工。取消同样结算原输入，不留永久堵塞消息。

人工在企微回复时，message.self_sent事件关闭该客户autoReply并使未提交草稿失效。本人在列表点「恢复」后只处理新消息，不补发旧稿。已经提交给网关的动作只能核实原结果。

## 在哪里看

- 项目列表：最近消息、时间、自动回复/暂停、搜索、每页50人。
- 点击客户：原生Session查看专家方法、工具调用和生成说明；「返回自动应答」回列表。
- 同一个Session顶栏「渠道记录」：最近50条入站和50条回复，包括尚未进入模型的暂停/人工消息及真实发送状态。它是只读渠道核对，不是第二套聊天或模型轮次。
- 仅接管、异常提醒今日及配置好的本人渠道；正常每条成功回复不另行打扰本人。

原生Harness把未发生模型轮次的会话视为blank；专项仅调整这种客户会话的展示投影，并提供上述只读渠道记录，不伪造turn或调用模型。其余聊天与执行组件原样复用。

## 网关薄适配（部署私有配置示例）

```json
{
  "id":"my-gateway", "kind":"wecom-gateway", "enabled":false,
  "receive":true, "receiveMode":"poll",
  "baseUrl":"https://gateway.example.com/api/v1",
  "tenantId":"供应商租户编号", "accountId":"供应商托管账号编号",
  "apiKeyEnv":"WORKBENCH_GATEWAY_MAIN_API",
  "webhookSecretEnv":"WORKBENCH_GATEWAY_MAIN_HOOK",
  "allowedContacts":["独立测试联系人编号"]
}
```

沿用现有连接器服务，不增加后台服务。先用认证的只读事件轮询，首次只从当前水位接新消息，不重放旧客户历史，也不修改旧回调。适配支持签名回调时，用/hooks/连接器ID接原始字节并校验HMAC和时间；公网反代须明确指向本项目连接器，不能覆盖旧业务路径。

Transport使用同一个连接器ID、现有MCP端点、私有token环境变量和该项目允许列表。网关发送只用固定账号与原私聊对象，白名单同时限制收和发；群消息、历史回补和非文本客户消息不触发AI，非文本人工消息仍可触发停答。

accepted只代表网关受理；sent/delivered必须来自真实回执。网络超时保留unknown，查询原messageId，不盲目重发。保留实际平台编号和原始业务记录；业务正文、凭证及日志不进Git。

## 本次交付边界

已通过隔离MySQL的一万会话分页、资料隔离、接管/恢复/旧稿阻断，以及真实Harness/Temporal五个合成客户的专家和工具链。合成联系人被白名单挡在外发前，实际客户外发为零。

本人真实账号在验收时读回offline/sendEnabled=false。用户明确要求延后真实企微联测，先部署；因此正式接入默认停用，真实入站/外发/人工接管与回执不记为已验收。恢复账号后，先只允许本人测试联系人，完成一条真实收发及接管/恢复再开放更多对象。
