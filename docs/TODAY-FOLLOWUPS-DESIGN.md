# Product Design：今天的持续跟进

2026-11-04。视觉来源为现有 Today 代码和本次隔离 API 的实际页面截图。用户已明确授权本地 Playwright 作为浏览器不可用时的替代。

## 现状捕获与审视

1. 桌面进入今天：保留暖白背景、绿色强调色、系统中文字体、主对话/已有安排布局；每日建议和决策在消息流内，历史较长时需上滚才能找到。截图 `artifacts/today-followups/01-before-desktop.png`。
2. 手机关闭已有安排：保留原有抽屉行为与输入框；可用宽度有限，新增内容应短行换行、避免并排工具栏。截图 `artifacts/today-followups/02-before-mobile.png`。

首次过早捕获的加载态已拒绝；最终基线等待真实内容出现后重新捕获并打开查看。截图不能证明全部键盘与屏幕阅读器行为，后续另做交互验证。

## 视觉目标与增量规格

现有产品就是视觉目标，不创建新主题/导航。使用当前字体、`--green`、`--muted`、`--line`、原决策卡与 Lucide 图标。

在今天页头下增加稳定可见的折叠入口“持续跟进”，显示进行中的数量和待决定数量；展开时区域独立限高滚动，不挤掉底部输入框。条目呈现标题、状态和下次复查时间，展开才显示完成条件、进展、依据与操作。

待决定条目内复用 DecisionCard，消息流不再重复呈现同一问题。待核实可继续，待复查可立即核实，已完成/取消归入折叠历史。取消采用条目内二次选择，保留操作结果和消息草稿。忙碌、失败和版本冲突有明确反馈，不跳转其他项目或隐含项目写授权。

桌面保留主对话和已有安排；390/320px 宽度下条目纵向流动，标题和长依据可断行。主操作至少 40px 高，折叠按钮带 aria-expanded 和区域关联，异步反馈使用现有通知并保留选择。

## 验证计划

使用真实本地 Store/API 和确定性 Executor 的隔离夹具。比较相同视口的前后捕获，检查保留区域的字体/间距/颜色和新增区域层级；对跟进详情做可读的聚焦截图。覆盖展开收起、决策回答后续办结案、继续核实、取消复查、历史查看、失败保留、键盘焦点、输入草稿与手机无横向溢出。最终结果记录到 `design-qa.md`，不以构建成功代替视觉验证。
