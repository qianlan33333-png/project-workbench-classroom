2026-10-30，Linux amd64 / Ubuntu 24.04，正式发行 cloud-20261030-03。记录区分替身行为测试、真实 Harness／模型、真实平台及用户可见检查。

## 已自动验证

Go 18 项普通用例通过 `go test -race ./...`，`go vet ./...` 通过；另有 4 项真实测试由 PW_REAL_CONFIG 启用，不计作默认跳过项的通过。TypeScript/Vite 构建通过。Node 渠道 6 项测试通过。

| 对抗场景 | 自动测试结果 |
|---|---|
| 同一微信 A→B→A，飞书另有焦点 | Session/Harness ID 不变，各渠道焦点独立 |
| 引用旧任务／专题、对话 URL | 进入原对话，不修改所属项目；通知不改焦点 |
| 两项目关键词重叠、附件内切换指令 | 保留原消息并澄清；正文外的附件名称不能授予项目访问 |
| 本人、私聊、重复及迟到输入 | 非本人／群聊拒绝；重复事件一次执行；不同正文同 ID 报错；旧问题失效 |
| 引用／最近已送达线索 | 明确引用与辅助线索分别标记，限定原渠道 |
| 同专家用于 A/B、专家更新 | 方法复用，项目笔记隔离；排队运行固定全部能力包摘要 |
| 显式跨项目引用 | 仅给指定文件授权；原消息不被修改，重复提交仍稳定 |
| 文件写锁／CAS／撤销 | 锁内禁止手动覆盖，撤销不覆盖后续修改，路径与符号链接越界拒绝 |
| 执行取消／崩溃 | 先收拢进程再记录差异解锁；清理失败保留锁；claim 与执行间的停止有效 |
| 定时重复／错过 | 同次触发去重，错过多次合并；独立 Session，不污染默认助手 |
| 发送状态不明 | 不再领取自动发送；保留平台回执和分段回执 |
| 二进制与 SSE | 图片以原字节读回，不能当作文本编辑；Last-Event-ID 续读；停机关闭 SSE |
| Node 发行符号链接 | 通过 current 启动时真正运行主入口；64 位微信消息 ID 不丢精度 |
