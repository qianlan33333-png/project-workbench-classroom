## 专项故障与结构验证

| 场景 | 本地验证结果 |
|---|---|
| 两个项目、相同联系人 ID、不同账号 | 独立 Session/项目及发送目标 |
| 重复事件、不同事件中的同一消息 | 只运行和发送一次；变更内容的同一事件拒绝 |
| 人工回复后模型迟到、暂停再恢复 | 旧结果失效，旧排队输入不重放，人工回复来源保留 |
| 转人工、飞书失败与崩溃恢复 | 人工模式保持，通知事务提交，固定幂等键恢复 |
| HTTP 接收后丢失回执 | 原键原正文恢复，物理发送一次 |
| 网关明确 unknown | 不自动重发，转人工核对 |
| HTTP 202、异步 sent 与迟到快照 | accepted 与 sent 分离，最终状态不倒退 |
| 绑定更换、连接停用再启用 | 旧任务失效，旧会话归属不改，不能静默接管其他项目账号 |
| 未配置绑定时收到回调 | 不提前确认，去重事务回滚，完成绑定后原事件可恢复 |
| 伪造来源、签名、时间窗、头体 ID 不一致 | 拒绝接收或执行 |
| 客户控制命令、全局工具管理、读取其他客户 | 不进入控制入口，权限拒绝；运行目录与发送凭证隔离 |
| 五客户与内部长任务争用项目锁 | 不绕过写锁，达到期限转人工；不等于五客户吞吐已通过 |
| 更换业务 | CLI 两份配置与宿主两项目共用相同实现，无专属业务分支 |
