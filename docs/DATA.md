# 导入、导出与恢复

项目文件是普通目录。网页项目文件栏支持目录或 ZIP 导入，保留相对路径、中文文件名、Markdown、Frontmatter、双链、附件和 `.obsidian` 配置。空目录也保留。不运行 Obsidian 插件，不做双向同步。

导入不会覆盖已有同名文件。先在隔离临时目录检查压缩包，再逐文件写入及记录版本；若磁盘或 I/O 失败，已写入的文件仍有版本记录，错误会返回。第一版不承诺跨文件导入事务。

限制：项目最多 50000 个目录项；单个普通文件 128MB；导入 ZIP 解压总量 1GB；专家包 64MB。符号链接和特殊文件不能通过导入写入，不纳入普通文件导出／撤销；命令生成的普通文件，包括依赖目录中的文件，会记录变化。大型仓库和依赖目录宜使用运行环境缓存，避免把构建缓存写入项目资料。

项目菜单提供 ZIP 导出。导出需要当前项目没有写入任务，保证文件列表和内容一致。除单项目导出外，完整恢复必须同时保留 SQLite、projects、experts、blobs、runtime 和 uploads；仅复制正文不能恢复对话和文件历史。

文件历史显示前后内容，撤销会校验当前文件是否仍等于该修订的结果。后续任务或手动修改过同一文件时，撤销会拒绝覆盖。取消任务不会偷偷回滚已有成果。异常重启先杀掉遗留容器，再记录变化、标记中断、使旧问题失效和释放锁。

专家 ZIP 的根目录或单一顶层目录须含 `SKILL.md`。`name` 使用小写英文和连字符，中文展示名使用 `display-name`；网页创建中文专家会自动生成合法标识。Git 导入必须给完整 40 位 SHA。包更新只影响后续任务，已排队任务记录全部启用专家的内容版本；项目内笔记不会被包更新覆盖。

跨项目引用最多 20 份明确指定的文件，只读取 2MB 内文本，保留来源项目、路径和 SHA256。不会自动把另一个项目整段聊天复制进来。

微信和飞书的媒体先在项目外暂存，归属明确且取得写锁后才进入当前项目 `附件/`。微信支持 iLink 图片／文件／视频的下载解密，语音可保留原文件及平台提供的转写；不承诺解码所有语音格式。飞书支持文本、富文本及消息资源附件。媒体能力的真实平台覆盖情况见验收记录。

协议依据：[Tencent iLink 公开协议](https://github.com/Tencent/openclaw-weixin/blob/main/docs/protocol.md)、固定提交的 [Harness SDK](https://github.com/deepseek-ai/deepseek-harness/blob/ce7073d51254c26cd63b22a60835b8f948deb447/packages/sdk/protocol/README.zh.md)。具体收发能力以真实账户验证为准。
