# 导入、导出与恢复

项目文件是普通目录。网页文件栏的“添加”支持任意扩展名文件、多选、文件夹、ZIP 导入和新建文件／目录。普通上传 ZIP 保留原压缩文件；只有“导入 ZIP”执行解压。文件／文件夹可拖入，上传位置以面板显示的目标目录为准。目录导入保留相对路径、中文文件名、Markdown、Frontmatter、双链、附件和 `.obsidian` 配置。空目录也保留。不运行 Obsidian 插件，不做双向同步。

ZIP 导入不会覆盖已有同名文件，冲突会列出路径并允许修改目标目录。普通上传冲突可选择跳过、保留两份、替换；替换校验旧 hash 并生成修订。文件栏上传不附加到聊天，聊天上传进入“附件”并加入本次输入。

先在隔离临时目录检查压缩包，再逐文件写入及记录版本；若磁盘或 I/O 失败，已写入的文件仍有版本记录，错误会返回。第一版不承诺跨文件导入事务。

限制：项目最多 50000 个目录项；单个普通文件 128MiB；ZIP 请求 512MiB、解压总量 1GiB；专家包总量 64MiB。在线编辑与全文索引仅处理 2MiB 内 UTF-8 无 NUL 文本，包括 `.md`、`.MD`、`.markdown`、代码、JSON、CSV。更大文件、Office、未知格式及非 UTF-8 内容保留原字节并可下载；不隐式转换编码，不提供 Office 在线编辑。图片、PDF 和 MP4/WebM 使用对应预览。符号链接和特殊文件不能通过导入写入，不纳入普通文件导出／撤销；命令生成的普通文件，包括依赖目录中的文件，会记录变化。大型仓库和依赖目录宜使用运行环境缓存，避免把构建缓存写入项目资料。

项目菜单提供 ZIP 导出。导出需要当前项目没有写入任务，保证文件列表和内容一致。除单项目导出外，完整恢复必须同时保留 SQLite、projects、experts、blobs、runtime 和 uploads；仅复制正文不能恢复对话和文件历史。

文件历史显示前后内容，撤销会校验当前文件是否仍等于该修订的结果。后续任务或手动修改过同一文件时，撤销会拒绝覆盖。取消任务不会偷偷回滚已有成果。异常重启先杀掉遗留容器，再记录变化、标记中断、使旧问题失效和释放锁。

专家 ZIP 的根目录或单一顶层目录须含 `SKILL.md`。`name` 使用小写英文和连字符，中文展示名使用 `display-name`；网页创建中文专家会自动生成合法标识。Git 导入必须给完整 40 位 SHA。包更新只影响后续任务，已排队任务记录全部启用专家的内容版本；项目内笔记不会被包更新覆盖。

专家详情修改使用读取时 `baseDigest`，在临时目录校验后发布完整不可变版本；元数据表单保留未知 Frontmatter 字段和内部 Skill 标识。根 `SKILL.md` 不可单独删除或重命名。删除专家会清理后续选择并暂停显式绑定的定时任务，原因保存为 `pausedReason`；项目笔记及历史成果保留。已提交任务的名称、说明和方法从固定版本读取，更新或删除专家不影响它。

跨项目引用最多 20 份明确指定的文件，只读取 2MB 内文本，保留来源项目、路径和 SHA256。不会自动把另一个项目整段聊天复制进来。

微信和飞书的媒体先在项目外暂存，归属明确且取得写锁后才进入当前项目 `附件/`。微信支持 iLink 图片／文件／视频的下载解密，语音可保留原文件及平台提供的转写；不承诺解码所有语音格式。飞书支持文本、富文本及消息资源附件。媒体能力的真实平台覆盖情况见验收记录。

协议依据：[Tencent iLink 公开协议](https://github.com/Tencent/openclaw-weixin/blob/main/docs/protocol.md)、固定提交的 [Harness SDK](https://github.com/deepseek-ai/deepseek-harness/blob/ce7073d51254c26cd63b22a60835b8f948deb447/packages/sdk/protocol/README.zh.md)。具体收发能力以真实账户验证为准。
