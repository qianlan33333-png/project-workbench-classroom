# Today 第3版实现 review

范围：cb7e0f9之后的Today、个性化、附件上传/归集/读取及其直接消费者。此轮为当前执行者的源码review与复核，不声称独立代理审查。

## 已修复并复核

- 个人网页附件原本全部拒绝。现在绑定本人、web来源和当前个人Session；项目路径仍拒绝，其他项目和渠道不能消费该网页上传。物化用os.Root，归集重入校验实际内容。
- 附件解析曾存在子进程输出磁盘增长和取消后子进程残留风险。现为有界管道，固定程序、30秒期限，Go收拢整个进程组；桥关闭等待读取结束，然后容器和暂存清理。生产读取容器无网络、无凭证/项目挂载并限量。
- 规则重载过程中编辑可能被迟到的响应覆盖：加载时禁用表单；409保留草稿，不自动覆盖。
- 弹层出现时inert先改变焦点，关闭可能回不到入口：显式保存入口引用，恢复焦点；陷阱包含summary及按需证据链接。
- 残留绿色、旧页头预留空白、偏小的记忆字号/输入框、全局提示覆盖底部按钮：统一中性颜色，取消旧padding，按选中图调整，提示移到上方。
- 8项附件限制只作用于个人会话，不额外改变业务项目已有附件数量行为。

## 复核结论

未发现剩余可操作的P0/P1/P2问题。持久化/幂等仍使用原消息链；附件只写个人附件目录；原项目正文只读与跟进白名单不变。规则正文原样保存，不自动精简用户数据。纠正、遗忘、依据和原会话上下文重置语义保留。记忆变化会使旧问题依据失效，须重新核对后继续，浏览器验收覆盖了此分支。

本地浏览器使用真实隔离Store/API和固定文件解析器，模型为测试替身；另有单独的真实Harness内容验收，不将两者混称。生产Linux解析器、实际安装包与服务/渠道状态另列验收记录。
