## 候选范围

沿用原入口与持久个人会话，新增 bounded understanding + 限量依据检索。无新服务、向量库、导航模块或业务项目写权限。实施依据见 `PERSONAL_MEMORY_PRD.md`。

## 已验证的代码约束

- 正文最多 2400 Unicode 字符；150 条长细节的测试仍保留全部准确记录，常驻正文不超预算。
- 精确原话分页读取：列表最多 10 条/6000 字符，单条每次 4000 字符。
- 07:30 Asia/Shanghai 一次低优先级整理，有新内容才调用；初次迁移和手动刷新可触发。批次持久化 cursor/offset，早上建议优先于未完成整理。
- 首次从有效旧记忆初始化；源自旧 AI、缺少原话的条目保持待核；不扫描启用前聊天。
- 单次决策卡选择不作为证据；同源/同句不能伪装为多个独立支持。不同真实事件的语义归类仍由模型判断。
- 临时记忆未给期限默认七天；临时段落沿用证据失效时间，不续期。
- 纠正、来源变更和遗忘使相关段落立即退出有效理解；旧后台结果和旧页面不能覆盖当前状态。
- 普通修改不再设置原生会话重置；显式遗忘保留原生上下文清理与内容无关的排除账本。
- 只限当前对话/不记入个人记忆的明确表达被排除于学习及显式记忆工具。
- 运行中的能力和项目只读边界沿用既有工具白名单。

## 语义边界与遗忘影响

是否属于同一现实事件、哪项是反例、倾向的恰当措辞、临时信息的自然语言期限仍依赖模型判断。版本/来源/字数/只读限制由代码执行；验收实例通过不代表所有归纳必然正确，待核标记和纠正操作继续保留。

第一版显式遗忘会清理原生个人会话上下文，并排除被引用的来源消息继续参与学习；同一消息中其他派生理解可能一并退出。可见聊天不删除，应用 Session 身份保留。普通整理和纠正不执行此清理。

候选目录：`/opt/project-workbench/releases/cloud-20261102-15-personal-memory`。应用使用原 systemd 启动入口，容器与 Harness 固定依赖沿用。

发布：等待队列/活动任务结束，执行 `PW_RELEASE=cloud-20261102-15-personal-memory bash scripts/deploy-today.sh`。脚本停止渠道后复查，完整复制当前数据和配置，再切换并验证健康。
