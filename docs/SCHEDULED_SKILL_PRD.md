# 按项目启用的整理任务

任务到点或本人手动执行 → 在本地比较选定资料与上次成功版本 → 无变化记录跳过 → 有变化只派发一个 Run → 成功时同时发布结果和资料版本，失败或中断时记录原因并暂停，等待手工处理。

复用项目「定时」、独立会话、专家版本和项目写锁。执行条件可以是每次或资料变化，结果可以作为运行记录或发布为项目说明。整理方法随 SKILL.md 提供。大型结构化文件提供结构证据，覆盖缺口必须可见。默认没有整理任务。不接管旧定时任务，不恢复旧整理队列。保存、手动执行和启用分离，手动运行同样进行变化检查。重复提交、错过时点、服务重启不重放状态不明的操作。

参考 [OpenClaw 的本地命令与独立定时会话](https://docs.openclaw.ai/cli/cron)。验收覆盖无变化零模型、变化一次 Run、删除与人工修改冲突、失败停用、重启、手动幂等及实际 Harness 和渠道回归。
